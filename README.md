# Código Café

Sitio web de práctica del curso de desarrollo web. Incluye cinco páginas HTML, estilos personalizados con CSS, distribución con CSS Grid y Flexbox, y componentes de Bootstrap 5.

## Páginas

- `index.html`: inicio, tarjetas y preguntas frecuentes (accordion Bootstrap).
- `pages/galeria.html`: imágenes y carrusel Bootstrap.
- `pages/productos.html`: catálogo de productos.
- `pages/contacto.html`: formulario y mapa.
- `pages/nosotros.html`: historia y valores.

## Tecnologías y responsive

HTML5, CSS3, CSS Grid, Flexbox, Bootstrap 5.3.8 (CDN) y fuente Montserrat (Google Fonts). Se usa un enfoque mobile-first, con adaptaciones a partir de 768 px y 1024 px. Las cinco páginas tienen estilos adaptativos; se destacan Inicio, Galería y Contacto.

## Cómo visualizar

Abrí `index.html` en el navegador; necesitás conexión para cargar las dependencias por CDN. También podés publicar la carpeta en GitHub Pages.

## Historial de cambios

Se incluye la carpeta `.git` con **commits locales verificables** creados a partir del ZIP entregado para registrar estas correcciones; no representan los commits históricos de tu repositorio remoto original. Podés consultar el historial con `git log --oneline`.

Para conservar el historial real de GitHub, aplicá los archivos corregidos sobre un `git clone` de tu repositorio original y hacé ahí los nuevos commits; **no reemplaces la carpeta `.git` original por esta**.
